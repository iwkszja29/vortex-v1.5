CREDENTIAL MANAGEMENT

AppState

Credentials are validated and stored locally only. Never paste them into logs or share screenshots.

Saved AppState is never returned by the API. Only the validation result and connection status are displayed. “Remove session” disconnects the bot and deletes the locally saved AppState and refresh statistics; it does not delete commands, dashboard settings, or admin lists.

Operational notes

Use HTTPS in production, set strong environment secrets, and restrict repository and Railway access. JavaScript command editing is equivalent to code deployment and should be limited to trusted administrators.
